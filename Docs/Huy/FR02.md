## 1. Mô tả
Code Analyzer phân tích mã nguồn **Python** và **Java** bằng cây cú pháp (AST): Python dùng module `ast` có sẵn, Java dùng `tree-sitter` (`tree_sitter_java`). Kết quả là danh sách class, hàm/phương thức, tham số, kiểu trả về, docstring và endpoint, kèm vị trí dòng. GitHub Integration lấy file sau khi đồng bộ repository, gửi sang Analyzer, rồi chuyển kết quả cho AI Service làm đầu vào sinh tài liệu.

```
GitHub Integration /api/repositories/{id}/sync/latest/analysis-input
  -> Code Analyzer POST /api/v1/analyze-repo  -> files[]: classes, functions, endpoints
  -> AI Service /generate (sinh tài liệu)
```

---

## 2. Yêu cầu chức năng

| ID | Yêu cầu |
| :--- | :--- |
| **FR-AST-02.1** | Nhận danh sách file (`path`, `content`, `language` tuỳ chọn) của một file, module hoặc repository (`scope`, `target`). Không truyền `language` thì đoán theo đuôi file (`.py` → python, `.java` → java). |
| **FR-AST-02.2** | Trích xuất class (kể cả interface, enum, record), field, method, function, tham số (tên, kiểu, mặc định), kiểu trả về, docstring và endpoint HTTP (method, path, handler). |
| **FR-AST-02.3** | Ghi vị trí dòng bắt đầu và kết thúc (`lineno`, `end_lineno`) của từng thực thể, và tên module/package của file. |
| **FR-AST-02.4** | Mỗi file có trạng thái: `ok`, `empty` (file rỗng), `invalid` (lỗi cú pháp), `unsupported` (ngôn ngữ khác Python/Java). Một file lỗi không làm dừng các file còn lại. |
| **FR-AST-02.5** | File trùng đường dẫn chỉ phân tích bản đầu tiên và ghi cảnh báo vào `warnings`. |
| **FR-AST-02.6** | Trả về JSON chuẩn theo hợp đồng đầu vào/đầu ra (LD-395) để AI Service dùng trực tiếp. |

## 3. API

| Method | Endpoint | Kết quả | Yêu cầu |
| :--- | :--- | :--- | :--- |
| **POST** | `/api/v1/analyze-repo` | `200 OK` + `RepoAnalysisResponse` | FR-AST-02.1 – 02.6 |
| **GET** | `/health` | `200 OK` | Kiểm tra service |

Ví dụ body:
```json
{
  "target": "acme/shop",
  "scope": "repository",
  "files": [
    { "path": "app/services/cart.py", "content": "def get_total(cart):\n    return sum(cart)\n" }
  ]
}
```

Ví dụ kết quả (rút gọn):
```json
{
  "scope": "repository",
  "target": "acme/shop",
  "files": [
    {
      "path": "app/services/cart.py",
      "language": "python",
      "module": "app.services.cart",
      "status": "ok",
      "functions": [
        { "name": "get_total", "parameters": [{ "name": "cart" }], "lineno": 1, "end_lineno": 2 }
      ]
    }
  ],
  "warnings": []
}
```

---

## 4. Luồng chính
1. GitHub Integration đồng bộ repository và lấy nội dung các file Java/Python.
2. GitHub Integration gọi `POST /api/v1/analyze-repo` với danh sách file.
3. Analyzer xác định ngôn ngữ từng file, bỏ ký tự BOM, kiểm tra file rỗng.
4. Analyzer dựng AST (`ast` cho Python, tree-sitter cho Java) và trích xuất class, hàm, tham số, endpoint, vị trí dòng.
5. Kết quả từng file (kèm trạng thái) được gộp lại và trả về; AI Service dùng nó để sinh tài liệu và làm bằng chứng (evidence).

---

## 5. Luồng lỗi

| Trường hợp | HTTP | Kết quả |
| :--- | :--- | :--- |
| Danh sách `files` rỗng | `422` | `{"detail": "The list of files to analyze must not be empty."}` |
| File lỗi cú pháp | `200` | File đó có `status: "invalid"` và `error`; các file khác vẫn được phân tích |
| Ngôn ngữ không hỗ trợ | `200` | `status: "unsupported"`, `error: "Language '...' is not supported ..."` |
| File rỗng | `200` | `status: "empty"` |
| File trùng đường dẫn | `200` | Chỉ phân tích bản đầu, ghi vào `warnings` |

---

## 6. Quy tắc nghiệp vụ
* Chỉ hỗ trợ Python và Java. TypeScript/JavaScript chưa được hỗ trợ.
* Lỗi của một file không bao giờ làm hỏng cả lần phân tích; lỗi được ghi ở trạng thái của file đó.
* Module Python lấy từ đường dẫn (`app/services/cart.py` → `app.services.cart`); module Java lấy từ khai báo `package`, không có thì lấy theo thư mục sau `src/main/java/`.
* `app/dependency.py` đọc danh sách import của Python và Java để phân tích phụ thuộc.

---

## 7. Tiêu chí chấp nhận
* **AC-AST-02.1:** Trích xuất đúng tên, tham số và dòng bắt đầu/kết thúc của class và hàm trong file Python và Java mẫu.
* **AC-AST-02.2:** File lỗi cú pháp, file rỗng và file ngôn ngữ khác được đánh dấu đúng trạng thái, không làm dừng các file khác.
* **AC-AST-02.3:** Kết quả đúng hợp đồng JSON và được AI Service dùng để sinh tài liệu.
