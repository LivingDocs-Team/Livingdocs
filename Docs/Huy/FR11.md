## 1. Mô tả
Chức năng so sánh hai phiên bản của một tài liệu (UC-30, BR-44). Người dùng chọn hai version bất kỳ. Mặc định hệ thống so bản hiện tại với bản ngay trước nó. Kết quả hiển thị thành hai cột cạnh nhau, mỗi dòng được đánh dấu:
- **Thêm (added):** dòng chỉ có ở bản mới, tô màu xanh.
- **Xoá (removed):** dòng chỉ có ở bản cũ, tô màu đỏ.
- **Sửa (modified):** dòng có ở cả hai bản nhưng đã chỉnh sửa, tô màu vàng; chỉ phần chữ thay đổi được đánh dấu.
- **Không đổi (unchanged):** giữ nguyên; đoạn dài được gập lại.

Phía trên bảng có thống kê số dòng theo từng loại và danh sách các mục (heading) được thêm, xoá hoặc sửa, để người review nắm nhanh thay đổi.

```
Frontend (Approval History → Compare document versions)
  -> GET /api/document-workflows/{id}/versions                 (chọn version)
  -> GET /api/document-workflows/{id}/comparison?from=&to=     (kết quả so sánh)
       Backend BFF -> GitHub Integration (kiểm tra quyền xem workflow + chủ tài liệu)
         -> AI Service GET /internal/documents/{docId}/compare?from=&to=
              -> DocumentStore.compare -> doc_diff.diff_texts(bản cũ, bản mới)
Tab "Compare" trong phiên soạn thảo -> documentationDiff.js (cùng thuật toán, chạy trên trình duyệt)
```

## 4. Luồng chính
1. Người dùng mở **Documentation Management**, phần **Approval History**, và chọn một document workflow.
2. Frontend gọi `/versions`. Nếu có từ 2 version trở lên, ô **Newer version** chọn sẵn bản mới nhất, ô **Older version** chọn sẵn bản ngay trước.
3. Frontend gọi `/comparison?from=&to=`. GitHub Integration kiểm tra người dùng có quyền xem workflow và tài liệu thuộc chủ workflow, rồi chuyển request sang AI Service.
4. AI Service lấy nội dung hai version, so sánh và trả về các dòng, thống kê và mục thay đổi.
5. Giao diện hiển thị thống kê, danh sách mục đã đổi và bảng hai cột với màu theo từng loại dòng.
6. Người dùng chọn version khác hoặc bấm **⇄ Swap**; mỗi lần đổi, frontend gửi một request so sánh mới.
7. Khi đang soạn thảo, người dùng bấm **Create version**, sửa nội dung, mở tab **Compare** và chọn version: kết quả được tính ngay trên trình duyệt với cùng cách hiển thị.

## 5. Luồng lỗi

| Trường hợp | HTTP | Kết quả |
| :--- | :--- | :--- |
| Tài liệu có ít hơn 2 version (không truyền số version) | `409` | AI Service: `{"detail": "Create a version first to enable comparison."}`; GitHub Integration: code `DOCUMENT_COMPARISON_UNAVAILABLE`. Giao diện hiện "Create a version first to enable comparison." |
| `from` trùng `to` | `400` | `{"detail": "Select two different versions to compare."}`; GitHub Integration: code `DOCUMENT_COMPARISON_INVALID` |
| Số version nhỏ hơn 1 | `400` / `422` | GitHub Integration: `DOCUMENT_COMPARISON_INVALID` ("Version numbers start at 1."); AI Service: lỗi validation `422` |
| Version không tồn tại | `404` | `{"detail": "Version 9 not found"}` |
| Workflow không tồn tại, hoặc người dùng không có quyền xem | `404` | Lỗi chuẩn của GitHub Integration, không lộ thông tin tài liệu |
| Thiếu hoặc sai internal secret khi gọi AI Service | `401` | Từ chối |
| Chưa chọn đủ hai version trên giao diện | — | Không gửi request, hiện "Select a version to display the comparison." |
| Lỗi khác từ AI Service | `502` | GitHub Integration: `AI_SERVICE_FAILED`; giao diện hiện thông báo lỗi, không hiển thị kết quả giả |

## 6. Quy tắc nghiệp vụ
* So sánh luôn theo chiều `from` (bản cũ, cột trái) → `to` (bản mới, cột phải). Đảo chiều thì dòng thêm thành dòng xoá và ngược lại.
* Ngưỡng ghép dòng sửa: `MODIFIED_SIMILARITY = 0.5`. Dòng trống không bao giờ được ghép thành dòng sửa. Khi tìm dòng để ghép, chỉ nhìn trước tối đa 3 dòng.
* Mục (section) là heading `#` hoặc `##` gần nhất phía trên dòng. Dòng trước heading đầu tiên thuộc mục `(top of document)`. Dòng xoá tính vào mục của bản cũ; các dòng khác tính vào mục của bản mới.
* Ký tự xuống dòng `\r\n` và `\n` được coi như nhau.
* Quyền so sánh giống quyền xem tài liệu của workflow: Developer là chủ, Staff và Manager được xem workflow đó. Tài liệu phải thuộc chủ workflow.
* So sánh chỉ đọc dữ liệu, không tạo version mới, không ghi audit, không đổi database.
* Bản JS ở frontend (`documentationDiff.js`) cho cùng kết quả với AI Service, nhưng chỉ dùng cho nội dung đang có trong trang (tab Compare trong phiên).
